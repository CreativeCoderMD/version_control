## Выделение текста

Для выделения текста курсивом обрамите его звездочками - 
*Курсив.*

Для выделения текста полужирным обрамите его двойными звездочками - 
**Полужирный.**

Для выделения текста сразу обоими стилями обрамите его тройными звездочками -
***Жирный***

Для выделения зачеркнутого текста обрамите его тильдой -
`Зачеркнутый текст`

## Списки

Для создания ненумерованного списка необходимо выделить начало строки звездочкой и поставить пробел -
* Элемент 1
* Элемент 2
* Элемент 3

Для создания нумерованного списка необходимо начать список с цифры с точкой -
1. Первый элемент нумерованного списка
2. Второй элемент немерованного списка
